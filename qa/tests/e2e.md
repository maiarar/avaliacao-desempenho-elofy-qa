# Testes E2E - interface do usuário

> Idealmente, esses testes seriam executados primeiro manualmente, e após a validação, automatizados para garantir que o fluxo completo de avaliação de desempenho esteja funcionando conforme esperado
> Para contemplar o escopo da avaliação, irei descrever os passos aqui

## Cenários de teste

### Employee
1. Criação de um employee
2. Listagem de employees
3. Edição do employee
4. Exclusão do employee

### Time
1. Criação de um time
2. Listagem de times
3. Edição do time
4. Exclusão do time
